# ZenithVisuals 1.4.8

Клиентский визуальный мод для Minecraft 1.21.11 / Fabric / Java 21.

## Обновление 1.4.8
- Скруглённые края HUD, ClickGUI и HUD Editor перерисованы построчно с частичным покрытием крайних пикселей, чтобы уменьшить ступенчатость углов и неровные края панелей.
- В ClickGUI → Visuals добавлена переключаемая функция Fullbright. Она временно выставляет игровую гамму на максимальную яркость и возвращает исходное значение при выключении. Исходная гамма хранится в конфиге ZenithVisuals, в том числе при перезапуске клиента.

## Обновление 1.4.6
- HUD приведён к тёмному референсу G4bnCfjw: длинная капсула Watermark, Armor Status слева сверху, Active Bind справа, WASD слева, Jump Counter и FPS Graph внизу слева, эффекты зелий справа снизу.
- Убраны переливающиеся/радужные полосы. Используется один статичный акцентный цвет выбранной темы; Target HUD удалён, Target ESP оставлен отдельным модулем.
- ClickGUI сохранён в формате G4bnCfjw: пять узких полупрозрачных колонок поверх видимого мира.
- Оптимизировано рисование скруглённых панелей ClickGUI и HUD Editor: вместо отрисовки каждой строки используется несколько прямоугольников.
- Оптимизирован 3D Target ESP: методы VertexConsumer кешируются, снижено число сегментов и вершин; линия стала тоньше.
- FPS Graph получает значения с периодом 200 мс, график ограничен 24 точками.

## Установка
Положи `ZenithVisuals-1.4.8.jar` в папку `mods` вместе с Fabric API для Minecraft 1.21.11. Перед установкой удали старые версии ZenithVisuals.

## Сборка из исходников
Нужен JDK 21 и Gradle. На Windows запусти `СОБРАТЬ.bat` или выполни `gradle build`.

Компиляция Java и проверка ZIP/JAR не заменяют игровое тестирование.


## HUD 1.4.6
- Из HUD полностью убран Target HUD; Target ESP остаётся отдельной функцией.
- Добавлены отдельные Speed и Cooldowns, а также Staff Active по маркерам команд/префиксов в таблице игроков.
- Включены по умолчанию Timer Indicator (таймер сессии), Coordinates, Speed, Active Binds, Cooldowns и Staff Active.
- Для Cooldowns используется штатный ItemCooldownManager Minecraft 1.21.11.
- Staff Active зависит от того, помечает ли сервер персонал через названия команд или префиксы; скрытые роли без таких маркеров не определяются.
- Старый Timer Function из Forge-пасты не переносится: в Fabric-проекте нет `timerFunction` и его API. Вместо него используется безопасный таймер длительности текущей сессии.


### Fullbright (1.4.8)

В категории Visuals добавлена функция Fullbright. Она поднимает игровую гамму для устранения темноты и при выключении возвращает сохранённое пользователем значение. Исходная гамма сохраняется в `config/zenithvisuals.properties`, поэтому её можно восстановить и после перезапуска игры.
